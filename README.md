A static make.fun frontend: the live bounty board, a page for each bounty with its rewards and dates, its leaderboard, and an account's public profile, on hash routes and the public API. No framework, six files, about 11 KB gzipped on first load.

## Run it

node serve.ts
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
